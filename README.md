## Instrucciones:
1. Cree un repositorio PÚBLICO llamado de la siguiente forma:
```
ApellidosNombres_Grupo_(Letra que le corresponde)
Ejemplo: RicardoPerez_Grupo3_(H)
```
2. Clone este repositorio y continúe su parcial en el repositorio creado. *NOTA: Por favor verifique que SU repositorio esté correctamente creado *
3. En la rama ```main``` agregue la imagen.
4. Cree una rama llamada ```corregir-titulos``` para arreglar el título y subtítulos de las secciones en el formato correspondiente, aquí el fragmento de código con la sintaxis:
```
# Título (nombre de la receta)
## Subtítulos (Ingredientes y )
```
3. 
4. En la sección de ingredientes, no escribas las cantidades en números, solo en letras.
5. En la sección de instrucciones de cada receta comete a propósito 7 errores de ortografía, resáltalos y escríbelos en mayúscula.
6. Agregar una imagen de internet (etiqueta IMG de HTML5)
